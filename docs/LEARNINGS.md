# 本機資料重現性補強

promote: yes

【實測】本 repo 的薪資桶加總與 `contributors_n` 一致；用 `employed_n` 當分母會誤判。欄位名稱、來源顆粒度與實際母數應分開核對，不能只檢查 join 有沒有產生列。

【實測】校系未分類與缺分數有交集；缺值聯集 84，不是兩個缺值數量相加的 86。原表的 7 筆達成率超過 100% 仍能重算，故本次將「表格一致性」與「來源品質」分成兩種檢查；嚴格品質入口保留失敗結果。

【限制】上述是這組隨附 CSV 的結果，未重抓原始來源，也未證明對其他專案有效。改動保持原始資料、薪資學門粒度與既有殘差排序。回歸測試包含手算小例與資料損毀反例；測試通過不構成真實校系薪資預測能力。

【實測】獨立審查發現，先排除缺分數列才做 join，會讓該列的未知學門漏檢。所有非空來源學門都應先核對薪資學門集合，再決定哪些合法缺值列不參與分析；缺分數不是略過 key 完整性驗證的理由。
